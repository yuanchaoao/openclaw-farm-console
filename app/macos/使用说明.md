# 管理台使用

使用根control.py安装并打开本机网页。首次设置填写自己的Linux SSH中继、用户、端口与专用密钥。Token存入原生系统凭据库。

流程：登记 → 真实Gateway/MCP验证 → 核对配对 → 授权文件桥写入/共享工作区/删除范围 → 远端回环服务 → 中继-R → 本机-L → 唯一测试文件读写删除。

文件桥默认使用本包校验程序，可选HTTPS来源由用户配置且校验批准哈希。下载失败保留健康程序。对象存储业务传输需要额外授权。

完整教程见 [首页](../../README.md)、[首次连接](../../docs/first-connection.md)、[配置](../../docs/configuration.md)、[文件操作](../../docs/files.md)、[生命周期](../../docs/installation.md)。验收以本次证据为准。
