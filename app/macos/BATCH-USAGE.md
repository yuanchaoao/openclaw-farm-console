# 批量安装与恢复

打开自己的Console连接中心，默认 http://127.0.0.1:4317/connections.html。

1. 添加链接、Token与备注，等待保存。
2. 核对稳定ID与范围，批量默认只允许纯数字显示名称。
3. 验通Gateway/MCP，核对各自设备配对。
4. 对授权范围启动“一键安装 / 修复所选文件桥”，明确共享工作区兼容与删除能力。
5. 每实例独立会话/端口/任务；真实能力和唯一文件写入、读回、删除通过才记完成。

命名实例需本次明确单独授权。移出列表是归档，不是远端卸载。见 [批量规则](../../docs/batch.md) 与 [恢复](../../docs/recovery.md)。本文不包含历史验收或公开默认服务器。
