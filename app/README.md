# 应用源码

这是 [OpenClaw Farm Console](../README.md) 的应用目录。完整安装请使用仓库根 control.py 或 scripts/install 入口，不直接运行历史平台安装器。

- console：本机回环管理台与网页。
- openclaw-farm/scripts：CLI、17工具MCP、官方Gateway SDK adapter、文件桥与传输。
- openclaw-farm/SKILL.md：可选智能体操作说明。
- macos：兼容入口和测试；公开安装逻辑以根入口为准。

自己的配置、登记表、运行数据和凭据在安装后创建。恢复按 [实际下游证据](../docs/recovery.md) 执行。中继为自有Linux OpenSSH，任何供应商均可。
