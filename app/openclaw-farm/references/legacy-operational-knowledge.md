# Deprecated legacy methods

Deprecated: shared static keys, public unauthenticated bridges, plaintext tokens, unchecked downloads, non-atomic transfers, mass state deletion, arbitrary approval, READY/PID/ACK as success and indefinite waiting on stale receipts.
