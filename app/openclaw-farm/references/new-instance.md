# New instance

1. Install locally, configure the user's Linux OpenSSH relay.
2. Register exact URL/ID and import token through hidden input/protected stdin into native credentials.
3. Preserve device identity and verify the full pairing request/scopes on that instance. The authorized missing-bridge install may request its main agent via Responses to match the complete request/device IDs and approve original scopes; check alone and healthy-bridge reuse do not do this. Endpoint/tool access is required and model fees may apply. Fall back to exact manual approval if actual connectivity is not verified.
4. Authenticate Gateway and list sessions.
5. Authorize file-bridge writes/shared-workspace/delete scope.
6. Reuse verified assets or install approved package; check instance tunnel public key and exact relay port authorization.
7. Verify remote/relay/client capabilities and unique-file write/read/delete.
8. Save evidence, failed layer and continuation.

Do not grant blanket sudo, delete OpenClaw state, insert static keys, expose unauthenticated bridges or approve arbitrary requests. [Tutorial](../../../docs/first-connection.md), [relay](../../../docs/relay.md).
