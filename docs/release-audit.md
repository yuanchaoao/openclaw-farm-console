# 公开发布清单审计

本记录检查 2026-10-07 工作目录中的可发布 UTF-8 源码、测试、文档、示例和依赖清单。它记录检查范围与发现，不保证后续构建产物或用户数据经过同样审核。

## 隐私检查

按私钥块、常见密钥格式、长实例 ID、云实例标识、私人用户名/绝对路径、真实 IP 地址、外部域名和聊天/备份文件名扫描，并检查候选项。未发现需要替换的真实个人密钥、实例清单、主机地址、用户路径或聊天备份。测试里的合成 Token、示例域名、回环地址和目录测试值保留；这些不能用于访问真实服务。按项目要求保留的 yuanchaoao 版权声明与上游作者署名属于公开归属信息。

工作目录存在自动化运行产生的 Python 字节码缓存。最终归档必须排除 __pycache__、*.pyc、用户配置/数据、日志、备份、SSH 材料、系统凭据和下载的运行时资产。源码发布保留 runtime/node 的 package.json 与 package-lock.json；不能直接打包整份已安装目录。

清单是版本与来源记录，不是所有平台的安装结果。发行包生成后还须检查归档成员清单，确认没有加入当前用户的私有文件。依赖锁变化后重新生成清单，重新核对许可。
