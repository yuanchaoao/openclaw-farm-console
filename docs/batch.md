# 批量操作与批准

## 选择范围

批量流程默认只处理显示名称匹配 ^[0-9]+$ 的实例，例如名称 1、2、3。实例 ID 始终来自链接，不能把显示名当 ID；两个重名实例也不是同一对象。

命名实例属于保护范围。需要本次明确授权某一命名实例后才可进行单实例调用；Console API 使用 allowNamedInstance=true 表达此授权。批量生成与批量授权仍拒绝命名实例。不要临时把命名实例改成数字来绕过保护。底层 CLI/MCP 调用者必须自行遵守目标范围。

## 操作步骤

1. 先完成本机、中继和一个实例的完整验收。
2. 在连接中心粘贴或添加自己的实例：链接、Token、备注。批量粘贴格式为每行“链接 | Token | 备注”，不要把该文本保存到仓库或日志。
3. 等待“已保存”，核对链接中的 ID、显示名和本次选中范围。
4. 点击“检查并连接 MCP”，核对每个实例独立的状态与设备申请；此检查不自动批准。
5. 选中数字名称实例，启动“一键安装 / 修复所选文件桥”，只勾选本次授权的共享工作区与删除能力。缺失文件桥安装时会尝试通过对应实例 Responses 请求主 agent 核对完整申请 ID/设备 ID 并批准原权限，再逐实例验证 Gateway；远端入口或工具权限不足时按该行提示人工批准。已有健康桥的复用分支不触发自动批准。详见 [首次连接](first-connection.md)。
6. 每行独立处理、独立端口、独立维护会话。一个实例受阻应显示断点和下一步，其他健康实例继续。
7. 按每行真实健康与文件读写删除结果验收；不能把批次请求接受数作为成功数。

手动两段提示词 API 每批允许 1–20 个实例；实时状态 API 每次最多 50 个。并发数量由性能配置和实际吞吐决定，不是成功凭证。先复用健康连接，再扩充新的连接能力。

## 三种远端批准

| 类型 | 核对什么 | 作用 |
|---|---|---|
| 本机设备配对 | 实例、完整配对请求 ID、设备公钥/身份、请求权限 | 允许该客户端访问 Gateway |
| 远端内部客户端权限 | 当前远端运行用户、状态目录、磁盘设备公钥、当前申请公钥与权限 | 修复远端内部调用链；不能凭“Linux/repair”标记批准任意申请 |
| 命令执行 allow-once | 本任务准确命令、实例、完整执行请求 UUID | 只允许一次执行；不能代替设备配对 |

文件桥安装写入、共享工作区兼容模式、服务删除能力，以及实际文件删除目标，还需要各自相应的任务授权。自动设备配对不代替远端内部客户端权限和命令执行批准；Responses 调用也可能产生远端模型费用。已有一项批准时复用它的有效证据，不重复批准同一设备；范围变化时重新核对。

## 移出列表

“移出列表”会把实例从当前管理范围归档，停止后续检查/安装。凭据和历史任务不立即销毁；旧窗口刷新不能自动恢复归档实例。它不卸载远端文件桥、不中断其他实例，也不等于撤销中继授权。彻底清理见 [安装与卸载](installation.md)。
